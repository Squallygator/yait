Simulation Dry run: nothing is written to your collection. These collisions are settled in the plan, before anything moves. mode: dry-run

Name collisions

Two or more files would get the same name. Names are compared across the whole collection, not folder by folder, because the end result is often one flat folder. Every file is kept: the best copy keeps the clean name, the others get _1, _2…

Order of the tie-break: 1 resolution (larger first), then 2 file size (larger first), then 3 time taken (earlier first), then 4 path (alphabetical, only so the result is the same on every run). The criterion that decided each case is marked ▶.
